# Santos Agri - Website

Website oficial da **Santos Agri**, empresa brasileira especializada em comercialização e intermediação de grãos e sementes.

## 🌾 Sobre

Santos Agri é uma empresa baseada em Luís Eduardo Magalhães - BA com mais de 15 anos de experiência exportando produtos para mercados na Europa, Oriente Médio e Ásia.

### Produtos
- Soja
- Milho
- Sorgo
- Caroço de Algodão
- Milheto
- Fertilizantes
- Gesso Agrícola
- Pluma de Algodão
- Calcário Agrícola

## 🚀 Tecnologia

- **CMS**: WordPress 7.0.2
- **Theme**: Dunay (customizado)
- **Idiomas**: Português (BR) e Inglês
- **Design**: Responsivo, mobile-first

## 📋 Seções

- **Hero**: Vídeo background com call-to-action
- **Sobre Nós**: Missão e valores
- **Serviços**: Cultivo, Armazenagem, Processamento, Entrega
- **Produtos**: Catálogo com filtros
- **Vantagens**: 7 diferenciais competitivos
- **Documentação**: Certificações e segurança comercial
- **Alcance Global**: Presença internacional
- **Contato**: Formulário e informações

## 💻 Como usar localmente

```bash
# Iniciar servidor local na porta 8000
python3 -m http.server 8000

# Abrir no navegador
# http://localhost:8000
```
